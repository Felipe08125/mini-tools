# mini-tools

Colección de scripts pequeños que voy haciendo para resolver cosas del día a día. Cada carpeta es una herramienta independiente con su propio README.

| Herramienta | Qué hace |
|-------------|----------|
| [bugreport-analyzer](./bugreport-analyzer) | Analiza informes de errores (bugreport) de Android con diagnóstico técnico y resumen claro |
| [instagram-unfollowers](./instagram-unfollowers) | Compara seguidores y seguidos desde el export oficial de Instagram |

## Estructura

```
mini-tools/
├── bugreport-analyzer/
│   ├── main.py
│   ├── html_report.py
│   ├── test_analyzer.py
│   └── README.md
├── instagram-unfollowers/
│   ├── main.py
│   └── README.md
└── README.md
```
